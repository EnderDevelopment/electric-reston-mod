# Menga Electric Mod for Minecraft Bedrock

Menga Electric is a Minecraft mod for Bedrock Edition that adds a simple electric power system. It introduces the Reston battery with 150 charge units, a Black Reston that appears when a Reston is fully discharged, and a Reston Block that stores 15,000 units of electric energy and charges Reston batteries. This mod provides a straightforward way to manage portable power in your Minecraft world, making it ideal for players who want basic energy storage and item charging mechanics.

## Install

1. Download the mod file `mengelectric-1.0.0.jar` from the repository.
2. Locate your Minecraft Bedrock Edition installation folder.
3. Navigate to the `mods` folder (if it doesn't exist, create it).
4. Place the downloaded `.jar` file into the `mods` folder.

## Use

1. **Craft a Reston Block**: Fill a 3×3 crafting grid with 9 Reston batteries to create a Reston Block.
2. **Place the Reston Block**: Right-click on the ground to place it in the world.
3. **Open the Reston Block menu**: Right-click on the placed block to open its interface.
4. **Charge Reston batteries**: Put a Black Reston (or a partially charged Reston) into the slot of the Reston Block menu. The block will automatically charge the battery if it has stored energy.
5. **Use the Reston battery**: Hold a Reston in your hand and right-click to use it. Each use consumes 10 charge. When the charge reaches 0, the Reston turns into a Black Reston.
6. **Check charge level**: The Reston battery has a green durability bar that shows its remaining charge.

The Reston Block can store up to 15,000 electric units. Charging a Black Reston into a full Reston (150 charge) costs 150 electric from the block.
